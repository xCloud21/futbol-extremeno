# Fútbol Extremeño

Web dedicada al fútbol modesto de Extremadura.

## Stack

- Vite
- JavaScript
- HTML
- CSS

## Estructura

- `index.html`: esqueleto principal y marcado estático.
- `src/main.js`: lógica de la aplicación, datos de ejemplo, renderizado y eventos.
- `src/style.css`: estilos.
- `public/data/`: preparada para datos JSON.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Los equipos y resultados incluidos actualmente son **datos ficticios de demostración**.
